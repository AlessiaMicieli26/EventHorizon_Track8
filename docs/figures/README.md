# Figures and Visual Results

Here you can collect the figures generated by your evaluation scripts. Scatterplots, temporal metric graphs (loss/accuracy curve), and qualitative previews of modified images.

Use this folder to link figures directly in the main `README.md` or in your presentation.

Generated evaluation figures:

- `metric_scatter_accuracy_f1.png`: scatterplot comparing target accuracy and macro-F1.
- `classifier_temporal_metrics.png`: source-only vs CycleGAN-augmented classifier loss, validation accuracy, and validation macro-F1 curves.
- `cyclegan_temporal_losses.png`: CycleGAN generator and discriminator loss curves.
- `qualitative_translation_previews.png`: original source slices, CycleGAN-translated slices, and absolute-difference previews.
